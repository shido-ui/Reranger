## Risk Summary
- **RSK-001 (S2):** Host memory pressure in Linux ARM64 PRoot container. Mitigation: Single-pass buffers, explicit isolate memory reclamation, segmented test execution.
- **RSK-002 (S2):** Local physical USB device absence. Mitigation: Mobile MCP physical cloud device fleet integrated and verified.
- **RSK-004 (S2):** Model file size (~1.78 GB total with anime LoRA) prevents base APK bundling. Mitigation: On-Demand Model Download Manager with SHA-256 checksum verification (ADR-0002).
- **RSK-005 (S2):** Out-Of-Memory kills on low-tier mobile devices. Mitigation: Hardware-gated studio activation based on total system RAM checks (ADR-0002) via `SCR-11` notice.
- **RSK-006 (S2):** Photorealism drift on 2D anime. Mitigation: Mandate anime-specialized cross-attention priors; clamp default slider to low strength ($s \in [0.15, 0.28]$).
